STEP 1

AI에게 이렇게 시키세요

코딩은 몰라도 됩니다. 아래 글을 그대로 복사해서 챗GPT·클로드·제미나이에 붙여넣고, 맨 아래 '우리 아이 정보'만 우리 집 아이 것으로 바꿔 주세요.

너는 초등학생 자녀를 둔 학부모를 돕는 다정한 선생님이야.
아래 내용으로 태블릿에 띄워 쓰는 '모닝 퀘스트 아침 대시보드'를 HTML 파일 1개로 만들어 줘.
파일은 하나만, CSS와 JavaScript도 모두 그 안에 넣어서 초보자도 그냥 열면 바로 되게 해 줘.

[분위기]
- 초등 1~3학년이 아침에 혼자 태블릿을 켜도 신나는, 밝고 귀여운 게임 같은 화면.
- 크림·민트·스카이·핑크·골드 파스텔 색, 둥근 카드, 큰 글씨, 이모지와 직접 그린 듯한 귀여운 일러스트.
- 태블릿 가로 화면에서도, 스마트폰에서도 예쁘게 (반응형).

[꼭 들어갈 것]
1) 상단 메뉴 바: 로고 '🌟 모닝 퀘스트' + 탭(🏠 대시보드 / 📖 공부·숙제 / 🏆 캐릭터 도감 / ⚙️ 엄마 설정 / 🪄 5분 만에 만들기)
   + 오른쪽에 🔊 효과음 켜기·끄기, ⛶ 전체화면 버튼.
2) 왼쪽 카드: 실제 현재 시각이 1초마다 바뀌는 큰 디지털 시계 + 오늘 날짜(예: 11월 21일 토요일).
   오른쪽 카드: 오늘 날씨(아이콘·기온·맑음/흐림) + 미세먼지 배지 + '따뜻한 외투에 목도리 챙기기!' 같은 한 줄 코멘트.
3) 분홍빛 긍정 확언 띠: '나는 오늘 새로운 것을 하나 배울 수 있어요.' + 🩷 응원 한마디 버튼(누르면 응원 팝업).
4) 등교 카운트다운: '등교까지 OO분 남았어요!' (설정한 등교 시각 기준 실시간)
   + 루틴 완료율만큼 마스코트가 달려가는 초록 게이지 바 + '루틴 0/4 완료'.
5) 오늘 방과후 준비물 알약 배너: '🎒 오늘 방과후 준비물: 리코더 · 실내화' / '다음은 내일: 줄넘기'.
6) 아침 루틴 4단계 큰 카드 (가로 4열, 모바일 2열):
   ① 아침 먹기 ② 세수·양치 ③ 옷 입기 ④ 가방·출발
   각 카드에 귀여운 파스텔 일러스트(SVG)를 직접 그리고, 카드를 누르면
   효과음 + 컨페티 폭죽 + '완료!' 도장 + 경험치 증가.
7) 4단계를 모두 끝내면 🎁 오늘의 보물상자가 열리고, 🏆 캐릭터 도감에 오늘의 몬스터가 해금됨.
   도감에는 12마리 몬스터가 있고, 잠긴 것은 실루엣으로 보여 줘.
8) 효과음은 외부 오디오 파일 없이 Web Audio API로 '띠링~', 레벨업 팡파레. 음소거 버튼도 꼭.

[꼭 지켜 줄 것]
- 새로고침해도 체크·경험치·도감이 그대로 남게 저장해 줘 (localStorage).
- 아이 손가락으로 누르기 쉽게 버튼과 카드를 크게.
- 완성된 코드 전체를 한 번에 복사할 수 있게 보여 줘.

[우리 아이 정보]
- 이름: 민준 (초등 3학년)
- 등교 시간: 08:30
- 마스코트: 아기 공룡
- 아침 루틴: 아침 먹기 / 세수·양치 / 옷 입기 / 가방·출발
- 오늘 방과후 준비물: 리코더, 실내화
- 오늘 급식: 치킨마요덮밥, 미역국, 소떡소떡
- 오늘 숙제: 받아쓰기 3번 쓰기, 수학 문제집 2장, 책 읽기 20분

(맨 아래 '우리 아이 정보'는 우리 집 아이 것으로 바꿔서 넣어 주세요.)

STEP 2

파일 하나로 저장하기

AI가 준 코드를 파일 1개로 저장하면 그게 바로 우리 집 앱이에요. 서버도, 프로그램 설치도 필요 없습니다.

  • PC라면 — 코드 전체를 복사 → 메모장에 붙여넣기 → 다른 이름으로 저장 → 이름 모닝퀘스트.html, 형식 모든 파일 → 저장 → 두 번 누르면 열려요.
  • 태블릿·휴대폰이라면 — app.netlify.com/drop 에 파일을 끌어다 놓으면 주소 하나가 바로 생겨요. (무료, 회원가입 없이도 가능)
  • 태블릿에 띄우기 — 생긴 주소를 태블릿 브라우저에 열고, 홈 화면에 추가하면 앱처럼 아이콘이 생깁니다.
⚠️ AI가 코드 앞뒤에 설명을 붙였다면, 설명은 빼고 <!DOCTYPE html> 부터 </html> 까지만 복사하세요. 저장이 안 되는 가장 흔한 이유예요.
