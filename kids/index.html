우리 아이 것으로 바꾸기

칸만 고치고 아래 저장 버튼을 누르면 끝!

저장한 내용은 이 브라우저에만 기억돼요. 아이 태블릿에서도 보려면 같은 방법으로 한 번 더 저장해 주세요.

STEP 1

AI에게 이렇게 시키세요

코딩은 하나도 몰라도 됩니다. 아래 글을 그대로 복사해서 챗GPT·클로드·제미나이에 붙여넣고, 대괄호 안의 우리 아이 정보만 바꿔 주세요.

너는 초등학생 자녀를 둔 학부모를 돕는 선생님이야.
아래 내용으로 '우리 아이 아침 대시보드'를 HTML 파일 1개로 만들어 줘.
파일은 하나만, CSS와 JavaScript도 모두 그 안에 넣어서 초보자도 그냥 열면 바로 되게 해 줘.

[만들 것]
1) 맨 위: 아이 이름으로 인사 + 오늘 모은 별 개수(진행 막대)
2) 오늘 아침 미션: 큰 체크 버튼. 누르면 체크 표시 + 별 1개
3) 오늘 시간표와 급식: 한눈에 보이게
4) 하교 후 일정: 시간 순서대로, 끝나면 아이가 직접 누르는 완료 버튼
5) 이번 주 별 모으기 판: 목표 개수까지 모으면 축하 문구

[꼭 지켜 줄 것]
- 새로고침해도 체크와 별이 그대로 남게 저장해 줘 (localStorage).
- 글씨는 크게, 버튼은 손가락으로 누르기 쉽게 크게, 이모지를 넣어서 초등 저학년도 혼자 쓸 수 있게.
- 색은 딥그린 #1F3D2B, 크림 #FAF8F2, 골드 #FFC24B 세 가지만 써서 차분하고 깔끔하게.
- 휴대폰 화면에서 먼저 예쁘게 보이게.
- 완성된 코드 전체를 한 번에 복사할 수 있게 보여 줘.

[우리 아이 정보]
- 이름: 민준 (초등 3학년)
- 아침 미션: 물 한 잔 마시기 / 알림장 준비물: 리코더, 실내화 / 체육복 입기 / 양치하기
- 오늘 시간표: 1교시 국어, 2교시 수학, 3교시 체육, 4교시 음악
- 오늘 급식: 치킨마요덮밥, 미역국, 소떡소떡
- 하교 후 일정: 15:00 태권도, 16:30 연산 2장, 17:30 책 읽기
- 이번 주 목표: 별 20개를 모으면 주말에 영화 + 팝콘

(위 '우리 아이 정보'는 우리 집 아이 것으로 바꿔서 넣어 주세요.)

💡 알림장 사진이 있다면, "이 사진 속 준비물과 시간표를 넣어 줘"라고 사진을 함께 올려도 됩니다.

STEP 2

파일 하나로 저장하기

AI가 준 코드를 파일 1개로 저장하면 그게 바로 우리 집 앱이에요. 서버도, 프로그램 설치도 필요 없습니다.

  • PC라면 — 코드 전체를 복사 → 메모장에 붙여넣기 → 파일 → 다른 이름으로 저장 → 파일 이름을 우리아이.html 로, 파일 형식을 모든 파일 로 → 저장 → 그 파일을 두 번 누르면 브라우저에서 열려요.
  • 휴대폰·태블릿이라면 — app.netlify.com/drop 을 열고 저장한 html 파일을 끌어다 놓기만 하면 주소 하나가 바로 생겨요. 그 주소를 아이 기기에도 보내 주세요. (무료, 회원가입 없이도 가능)
  • 글꼴·사진까지 예쁘게 — 표지 이미지가 필요하면 캔바로 만들고, html 안에는 넣지 않아도 됩니다.
⚠️ AI가 코드 앞뒤에 설명을 붙였다면, 설명은 빼고 <!DOCTYPE html> 부터 </html> 까지만 복사하세요. 이게 저장이 안 되는 가장 흔한 이유예요.
