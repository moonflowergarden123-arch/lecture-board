# 전국 유·초·중·고 학생 분포 히트맵

행정동 3,559개 단위로 학령인구 분포를 보는 인터랙티브 지도.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 스타일(더콘텐츠스쿨 컬러·페이퍼로지체) |
| `app.js` | 지도 렌더링(Canvas), 필터·검색·랭킹 |
| `data.json` | 행정동 3,559개 인구·면적 + 단순화 경계 (약 3MB) |
| `fonts/` | Paperozi 400·700 woff2 |

## 데이터 출처

* **인구·총인구·연령별 인구** — 행정안전부 주민등록인구통계, 2026년 10월 말 기준
  * 내려받기: `jumin.mois.go.kr` → 행정동별 연령별 인구현황 → 전체읍면동현황 xlsx
* **행정동 경계** — 통계청 SGIS 행정동 경계 2026.10.01 기준, 공개 배포본 `vuski/admdongkor` `ver20261001`
* **면적** — 경계 폴리곤의 측지 면적을 직접 계산(공식 시·군·구 면적과 1% 내외 오차)

## 수치 정의

* 유치원 = 만 3~5세, 초등학교 = 만 6~11세, 중학교 = 만 12~14세, 고등학교 = 만 15~17세 주민등록 인구
* 면적 km²당 = 학령인구 ÷ 면적(km²)
* 인구 1천명당 = 학령인구 ÷ (총인구 ÷ 1,000)
* 절대 학생 수 = 선택 학령군 합계

행정동 단위 재학생 통계는 공식 공표 자료가 없어 주민등록 학령인구로 산출했습니다.
경계가 없는 출장소 67곳의 인구는 해당 읍·면·동에 합산했습니다.
