# 🎓 연수 사이트 · 교사 AI 놀이실

충주성심학교 청주파견학급 연수(2026-12-14 교사편 / 12-15 학부모편) 교안으로 만든 **lecpage 스타일 테스트 연수 사이트**입니다.
https://moonflowergarden123-arch.github.io/lecture-board/chungju-ai-play/

## 무엇이 들어 있나

| 화면 | 내용 |
| --- | --- |
| 참가자 화면 | 오늘의 흐름 · 교안 슬라이드 19장 · 실습 프롬프트 6개(원클릭 복사) · 확인 퀴즈 4문항 · 투표 2개 · 질문 남기기 · QR 안내문 |
| 강사 화면 | 교안 목록·슬라이드 넘기기 · 실습 타이머(5·10·20·25분) · 퀴즈 정답 공개 · 투표 결과(샘플 응답) · 질문함 |
| 발표 화면 | 큰 슬라이드 + ←/→ 키 · 진행 막대 · 타이머 칩 · QR 전체 화면 |

- 상단 `DAY 1 / DAY 2`로 교사편(12/14)과 학부모편(12/15) 교안을 오갑니다.
- 강사 화면에서 장을 넘기면 **참가자 화면·발표 화면도 함께 넘어갑니다**(같은 브라우저의 탭끼리 localStorage로 동기화).
- `?mode=present`, `?mode=teacher` 주소로 특정 화면을 바로 열 수 있습니다. 강사 화면의 "발표 화면 열기(새 창)"가 이 주소로 엽니다.
- 투표·질문은 서버 없이 **그 브라우저 안에서만** 쌓이는 로컬 데모입니다. 실제 연수에서 참가자 응답을 모으려면 별도 저장소(예: 프롬프트 보드처럼 서버가 있는 보드)가 필요합니다.

## 파일

```
index.html          화면·스타일·데이터·동작 전부 (외부 CDN 없음)
fonts/Paperozi-*.woff2
vendor/qrcode.js    QR 생성 (MIT, Kazuhiko Arase) — 접속 주소를 그대로 담습니다
```

교안 내용은 `index.html` 안의 `DATA` 객체(`'1'`, `'2'`)에 있습니다. 슬라이드·프롬프트·퀴즈·투표를 고칠 때는 이 객체만 수정하면 됩니다.
