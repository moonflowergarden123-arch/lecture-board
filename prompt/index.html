    새 프롬프트 올리기

    목록 관리
    
        
    수정 · 삭제 · 📌 맨 위로 끌어올리기. 수정한 내용도 아래 ‘보드에 반영’으로 배포해야 수강생 화면에 반영됩니다.
    
        
      
        
      
          
          
        
      
      
      

      
      
        
      실시간 공유 설정 (GitHub)
      
        
      토큰을 한 번 저장해 두면 ‘보드에 바로 올리기’가 GitHub에 자동으로 커밋해 전 수강생 화면에 전파됩니다. 토큰은 이 브라우저(localStorage)에만 저장됩니다.
      
        
      
          
      
          
      
        
      
        
      
        
      
        
      
          
          
          
        
      
        
      
        
      토큰 만드는 법 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained token → Repository access에서 lecture-board 선택 → Permissions의 Contents: Read and write만 체크. 공용 PC에서는 사용 후 ‘토큰 삭제’를 눌러 주세요.
